# Linked List Management System

## Objective
A menu-driven console application to practice Singly and Doubly Linked List data structures in Java.

## Language Used
Java (JDK 8+)

## Features

### Singly Linked List
Insert (Beginning/End/Position/After/Before), Delete (Beginning/End/Position/By Value), Search, Update, Display, Count, Max, Min, Middle, Reverse, Sort, Remove Duplicates.

### Doubly Linked List
All operations above, plus Display Forward and Display Backward.
